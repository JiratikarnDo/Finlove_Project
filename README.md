# 🚀 Finlove Backend

Finlove Backend คือระบบ **API + Machine Learning Recommendation** สำหรับแอปพลิเคชัน Finlove (Online Dating Application)  
โดยออกแบบให้รองรับทั้ง Authentication, Profile Management, Chat และระบบ Hybrid Recommendation

---

## ✨ Features
- ระบบ Authentication (JWT, OTP ผ่าน Email)
- RESTful API สำหรับ Mobile App
- Hybrid Recommendation System (Machine Learning + User Preferences)
- จัดการฐานข้อมูลผู้ใช้ด้วย MySQL
- รองรับการอัปโหลดรูปภาพผู้ใช้

---

## 🛠️ Tech Stack
- **Node.js** (Express) – API & Authentication  
- **Python (Flask)** – Recommendation Engine (Hybrid ML Model)  
- **MySQL** – Database  
- **TensorFlow** – Machine Learning Model
